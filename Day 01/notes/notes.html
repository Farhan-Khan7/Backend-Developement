1. RUNNING JS OUTSIDE THE BROWSER

  • JavaScript is not a browser-only language.
  • Node.js lets us run JS directly on our computer — no Chrome, no HTML, no React needed.
  • This means JS can create servers, talk to databases, run scripts & power backend logic.
TECHNICAL DEFINITION Node.js is a JavaScript runtime environment that lets JS run outside the browser, using the V8 engine.

2. STEPS TO RUN A SCRIPT

  • Install Node.js → verify with node -v
  • Create a JS file, e.g. app.js
  • Write your code inside it
  • Open terminal in that folder & run the file
  • Output appears in the terminal, not the browser
console.log("Hello World from Node.js");
// run: node app.js

3. THE CLIENT–SERVER FLOW

CLIENT

Browser, mobile app, or Postman asks: "Give me data"

→
SERVER

Listens on a port, handles the request, sends back a response

→
RESPONSE

"Here is the data" — sent back to the client

4. WHAT ARE PACKAGES?

  • A package is code that you didn't write — some other dev made it public.
  • Used for: sending emails, encrypting passwords, creating servers, handling file uploads.
  • You borrow this code instead of writing it from scratch.
  • Packages are published on npmjs.com — think of npm as a store of JS code.

5. INSTALLING PACKAGES

  • Initialize a project → creates package.json
  • Install a package → npm install package-name
npm init -y
npm install express

6. WHAT HAPPENS INTERNALLY?

node_modules/

Actual package code lives here

package.json

Tracks which packages you installed & their versions

package-lock.json

Tracks exact dependency tree — same install across systems

7. USING A PACKAGE

  • Install the package first
  • Import it in your file
  • Then use its functionality
const express = require("express");
KEY RULE You cannot use a package without installing it first.

8. WHY EXPRESS?

  • Writing servers with plain Node.js is painful & verbose.
  • Express simplifies server creation.
  • Handles routing.
  • Handles middleware.

9. CREATE A SERVER — index.js

const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Server is running");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

Run with node index.js → open http://localhost:3000

10. WHAT'S HAPPENING?

  • app.get → defines a route
  • / → the endpoint
  • req → request from client
  • res → response from server
  • listen → starts the server

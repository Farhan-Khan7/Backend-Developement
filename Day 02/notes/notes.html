1. PROGRAM SERVER TO RESPOND TO USERS

What is a Server?

  • Listens for requests from clients (browser, mobile app, Postman)
  • Processes the request
  • Sends back a response
  • In web dev, servers usually respond via HTTP

Basic Express Server Code

const express = require('express');
const app = express();

// Route
app.get('/', (req, res) => {
  res.send('Hello User, Server is working!');
});

// Start server
app.listen(3000, () => {
  console.log('Server running on port 3000');
});
✓ Server running on port 3000

Explanation

  • express() → creates the server
  • app.get() → handles GET requests
  • req → request object (data from user)
  • res → response object (data sent back)
  • listen() → starts the server
⚠ COMMON PITFALLS 0/4
  • Forgetting to call app.listen()
  • Port already in use by another process
  • Missing res.send() → request hangs forever
  • Requiring express before installing it
🎤 INTERVIEW QUESTIONS
  • What is a server in Node.js?
  • What does app.get() do?
  • Difference between req and res?
  • What happens if you forget app.listen()?
✏ OPTIONAL TASKS 0/3
  • Add a second route, e.g. /about
  • Return JSON instead of plain text
  • Create a simple POST route

2. DEPLOY SERVER

What is Deployment?

DEFINITION Making your server available on the internet — not just on localhost.

Common Platforms

Render Railway Vercel (mostly frontend) AWS / DigitalOcean (advanced)

3. DEPLOYMENT STEPS

1. Push code to GitHub
↓
2. Connect repo to hosting service
↓
3. Add environment variables
↓
4. Build & start server

Conceptual flow — exact steps vary a little per platform, but this order stays the same.

⚠ COMMON PITFALLS 0/4
  • Forgetting to add environment variables
  • Hardcoding port instead of process.env.PORT
  • Pushing node_modules to GitHub
  • Not testing locally before deploying
ANALOGY
Deployment is like moving your shop from your home garage (localhost) to a shop on Main Street (the internet) — now anyone can walk in, not just you.
🎤 INTERVIEW QUESTIONS
  • What is deployment?
  • Difference between localhost and a deployed server?
  • Why can't Vercel easily host most Node/Express backends?
  • What are environment variables, and why do we need them?
✏ OPTIONAL TASKS 0/3
  • Deploy your Express server on Render or Railway
  • Add a .gitignore file to exclude node_modules
  • Use process.env.PORT instead of a hardcoded port
